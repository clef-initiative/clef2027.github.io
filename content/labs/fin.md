FIN is the second edition of the CLEF financial evaluation lab, previously known as FinMMEval. Its three tasks cover professional financial questions, rule application across financial frameworks, and evidence-based decisions in a simulated commodity market. Teams can enter each task independently.

<!--more-->

## Tasks

{{< accordion open_all="true" >}}
  {{< accordion-item title="FinExam: Professional Financial Reasoning" >}}
  Answer multiple-choice questions aligned with the CFA and FRM curricula, using any supplied case materials and exhibits.
  {{< /accordion-item >}}
  {{< accordion-item title="FinNorm: Islamic Financial Reasoning" >}}
  Apply the correct financial rule under an explicitly stated Islamic or conventional framework.
  {{< /accordion-item >}}
  {{< accordion-item title="FinTrade: Evidence-Grounded Trading" >}}
  Verify news, identify the affected commodity, and choose whether to trade under shared rules in a simulated market.
  {{< /accordion-item >}}
{{< /accordion >}}
